# Church Signage: feature backlog

Ideas saved for later, to add as features for other churches. Not scheduled yet.

## Classroom extras (proposed 2026-11-16)

Hiding tiles per room is already done: each room's layout on the Launchers page decides which tiles show.

1. **Parent paging.** Check-in or a nursery volunteer types a child's number ("#142"), and a banner shows on chosen TVs (sanctuary, lobby): "Parent of #142, please come to the Nursery." Clears after a few minutes or with one click. A role-limited page, so volunteers need no other access. The TV app can already draw over other apps. Later: pull numbers from Planning Center Check-Ins. *Question for each church: numbered tags or names?*
2. **Clean-up time.** Per layout, a time (for example Sunday 12:30 PM or nightly 9 PM) when the TV closes whatever app is open and returns to its home screen.
3. **Nightly sleep for classrooms.** Optional "sleep at 9 PM, wake on remote" per layout, using the signage TVs' existing sleep code.
4. **Video and playlist tiles.** Like website tiles, but open a specific YouTube video or playlist ("Kids Worship", "This Week's Lesson").
5. **"Need help" tile.** A teacher presses it and the dashboard shows "Room 104 needs tech help" on Now and in Activity. Email or text alerts would need the app to send mail, so start with the dashboard only.
6. **Room info line.** Under the room name: "3rd–5th Grade · Ms. Smith" or "Next: Youth Group 6:30 PM" (from a room calendar).
7. **Class timer.** A tile that shows a large 5, 10 or 15 minute countdown, then returns home.

Suggested order when picked up: paging; then clean-up time and nightly sleep; then video tiles.
